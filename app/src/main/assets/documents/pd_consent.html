1. Персональные данные

  • идентификатор пользователя Яндекса;
  • логин, отображаемое имя, имя и фамилия;
  • адрес электронной почты;
  • идентификатор и адрес изображения профиля;
  • OAuth-токен, необходимый для поддержания сессии.

2. Цель обработки

Данные используются для получения сведений профиля Яндекс ID, создания локального профиля ВольтХом, отображения имени и изображения пользователя и поддержания локальной авторизованной сессии.

3. Действия с данными

Сбор, получение, запись, систематизация, хранение, уточнение, использование, извлечение, удаление и уничтожение с применением средств автоматизации.

4. Условия хранения

Профиль и OAuth-токен хранятся на устройстве пользователя; токен размещается в защищённом хранилище. Оператор не создаёт на собственном сервере учётную запись пользователя и не переносит туда проекты. Передача запросов в Яндекс необходима для выполнения выбранного пользователем входа.

5. Срок действия и отзыв

Согласие действует до выхода из профиля, удаления локальных данных, отзыва доступа в настройках Яндекс ID либо получения Оператором отзыва согласия, если обработка не должна быть продолжена на ином законном основании.

Отзыв направляется на nnurkatova@list.ru. После отзыва пользователь может продолжить работу в гостевом режиме.

6. Способ предоставления

Согласие предоставляется отдельным активным действием в интерфейсе Приложения до запуска входа через Яндекс ID. Настоящее согласие не распространяется на техническую аналитику, покупки RuStore или содержимое локальных проектов.

Вход через Яндекс ID необязателен. Для гостевого режима это согласие не требуется.
