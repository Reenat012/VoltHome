2. Категории и цели обработки данных

Приложение VoltHome обрабатывает минимально необходимый объём персональных данных, исключительно для обеспечения работы сервиса, авторизации и улучшения качества приложения.

2.1. Авторизация через Яндекс ID

Для входа в приложение используется сервис Яндекс ID. В процессе авторизации Яндекс передаёт приложению:

  • уникальный идентификатор пользователя (uid);
  • имя и e-mail (если пользователь предоставил);
  • токены авторизации (sessionJwt, refreshId).

Эти данные применяются только для входа в аккаунт VoltHome и синхронизации данных. Они не используются для рекламы и не передаются третьим лицам.

2.2. Пользовательский профиль

После авторизации на сервер VoltHome сохраняются:

  • имя пользователя;
  • адрес электронной почты;
  • статус подписки (Free / PRO);
  • дата регистрации и последнего входа.

Информация необходима для идентификации пользователя, активации подписки PRO и синхронизации проектов.

2.3. Рабочие данные (проекты, комнаты, устройства)

VoltHome хранит данные проектов, групп и устройств для возможности синхронизации между устройствами. Эти сведения не позволяют идентифицировать конкретное лицо и не считаются персональными данными.

2.4. Аналитика и технические данные (AppMetrica)

Приложение использует SDK Yandex AppMetrica, который собирает обезличенные технические данные:

  • идентификатор установки (AppMetrica Device ID);
  • модель устройства, версия ОС и приложения;
  • технические события (например, первый запуск, ошибки).

Сбор ведётся исключительно для статистики и улучшения работы приложения. Пользователь может ограничить аналитику в настройках Android («Ограничить отслеживание рекламы»).

2.5. Telegram-бот и Telegram-канал

В приложении реализованы кнопки перехода в:

  • официальный Telegram-бот VoltHome — для консультаций и оформления заявок;
  • Telegram-канал VoltHome (@volthomeapp) — для новостей и советов по электрике.

При переходе в Telegram:

  • приложение не передаёт никаких пользовательских данных автоматически (только внешняя ссылка https://t.me/...);
  • дальнейшая обработка регулируется Политикой конфиденциальности Telegram;
  • при общении в боте пользователь добровольно предоставляет свои данные (имя, логин Telegram, текст обращения и, при желании, вложения);
  • эти данные используются исключительно для обратной связи и оказания консультации.

3. Передача и хранение данных

3.1. Сервер VoltHome

Данные пользователей хранятся на сервере VoltHome, размещённом на инфраструктуре российского хостинг-провайдера Timeweb (г. Санкт-Петербург). База данных PostgreSQL и серверное приложение работают в изолированном окружении. Передача данных осуществляется по защищённому протоколу HTTPS (TLS 1.3). Резервные копии создаются ежедневно и хранятся на территории РФ.

3.2. Сервисы третьих лиц

Сервис Цель использования Обрабатываемые данные Политика конфиденциальности
Яндекс ID Авторизация UID, имя, e-mail yandex.ru/legal/confidential
Yandex AppMetrica Аналитика и диагностика обезличенные события appmetrica.yandex.ru/about
Telegram Обратная связь и новости данные, предоставленные пользователем в чате telegram.org/privacy

4. Гарантии безопасности

  • Все соединения защищены протоколом HTTPS (TLS 1.3);
  • Локальная база данных шифруется средствами Android Keystore (AES-256);
  • Доступ к серверу VoltHome ограничен только разработчиком;
  • Данные не передаются третьим лицам без согласия пользователя;
  • Обезличенные аналитические данные не позволяют идентифицировать пользователя;
  • Данные, переданные через Telegram-бот, используются только для ответа и не сохраняются вне Telegram.

5. Права пользователя

Пользователь имеет право:

  • получить информацию о своих данных;
  • потребовать исправления или удаления данных;
  • отозвать согласие на обработку;
  • удалить аккаунт и все связанные проекты.

Для реализации прав можно отправить запрос на reenat056@yandex.ru или воспользоваться функцией «Удалить аккаунт» в приложении (если доступна). Запрос обрабатывается в течение 30 календарных дней.

6. Сроки хранения данных

  • Данные профиля и проектов хранятся до удаления аккаунта пользователем;
  • Резервные копии — не более 30 дней;
  • Обезличенные данные аналитики AppMetrica — не более 24 месяцев;
  • При удалении приложения локальные данные стираются средствами Android.

7. Основание обработки данных

Обработка персональных данных осуществляется на основании:

  • ст. 6 ФЗ-152 «О персональных данных» — исполнение пользовательского соглашения;
  • ст. 10 п. 1 ФЗ-152 — обработка общедоступных данных (например, сообщений в Telegram-боте);
  • согласия пользователя, выраженного при установке и использовании приложения.

8. Изменения в политике

При изменении способов обработки данных разработчик уведомляет пользователей:

  1. в описании обновления в магазине приложений;
  2. в Telegram-канале @volthomeapp;
  3. в разделе «Информация» → «Политика конфиденциальности» внутри приложения.
