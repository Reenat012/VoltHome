2. Категории и цели обработки данных

Приложение VoltHome обрабатывает минимально необходимый объём данных, исключительно для работы приложения, авторизации и улучшения его качества.

2.1. Авторизация через Яндекс ID

Для входа используется сервис Яндекс ID. В процессе авторизации Яндекс передаёт приложению следующие данные:

  • уникальный идентификатор пользователя (uid);
  • имя и e-mail (если пользователь предоставил);
  • токены авторизации (sessionJwt, refreshId).

Эти данные применяются только для входа в аккаунт VoltHome и синхронизации данных. Они не используются для рекламы и не передаются третьим лицам.

2.2. Пользовательский профиль

После авторизации на сервер VoltHome сохраняются:

  • имя пользователя;
  • адрес электронной почты;
  • статус подписки (например, free или pro).

Информация необходима для персонализации профиля, активации подписки PRO и доступа к проектам.

2.3. Рабочие данные (проекты, комнаты, устройства)

Приложение сохраняет проекты и связанные с ними данные на сервере VoltHome для синхронизации между устройствами. Эти данные не содержат сведений, позволяющих идентифицировать конкретное лицо.

2.4. Обезличенные аналитические данные (AppMetrica)

Используется аналитический SDK Yandex AppMetrica, который собирает обезличенные технические данные:

  • идентификатор установки (AppMetrica Device ID);
  • модель устройства и версия ОС;
  • версия приложения;
  • технические события (например, первый запуск).

Данные применяются исключительно для статистики, аналитики и оптимизации работы приложения. Пользователь может ограничить сбор аналитики через системные настройки Android («Ограничить отслеживание рекламы»).

3. Передача и хранение данных

3.1. Сервер VoltHome

Хранение и обработка пользовательских данных осуществляется на сервере VoltHome, размещённом на инфраструктуре российского хостинг-провайдера Timeweb (г. Санкт-Петербург, РФ). База данных PostgreSQL и серверное приложение работают в изолированном окружении, доступ к которому имеет только разработчик. Передача данных выполняется по защищённому протоколу HTTPS. Все данные резервируются и хранятся исключительно на территории Российской Федерации.

3.2. Сервисы Яндекса

Авторизация и аналитика обрабатываются сервисами ООО «Яндекс» (ИНН 7704352439, г. Москва) в соответствии с Политикой конфиденциальности Яндекса.

4. Гарантии безопасности

  • Все соединения между приложением и сервером защищены протоколом HTTPS;
  • Локальная база данных шифруется средствами Android Keystore (AES-256);
  • Доступ к серверу VoltHome ограничен только разработчиком;
  • Разработчик не передаёт данные третьим лицам;
  • Обезличенные аналитические данные не позволяют установить личность пользователя.

  • При удалении приложения локальные данные стираются средствами Android.

Обработка осуществляется на основании ст. 6 ФЗ-152 «О персональных данных» — для исполнения пользовательского соглашения и обеспечения работы приложения VoltHome.
