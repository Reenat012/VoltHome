2. Назначение сервиса

VoltHome предназначено для:

  • предварительных расчётов параметров систем электроснабжения;
  • организации и хранения проектов, комнат и устройств;
  • подготовки к профессиональному проектированию и консультациям.

Приложение не является профессиональной САПР и не заменяет услуги сертифицированных специалистов.

3. Принципы работы

3.1. Хранение данных

  • данные проектов сохраняются локально и синхронизируются с сервером VoltHome, размещённым на инфраструктуре российского хостинг-провайдера Timeweb (г. Санкт-Петербург, РФ);
  • передача данных выполняется по защищённому протоколу HTTPS;
  • разработчик не имеет доступа к содержимому пользовательских проектов.

3.2. Авторизация

  • вход осуществляется через сервис Яндекс ID;
  • данные (uid, имя, e-mail) используются только для идентификации пользователя и синхронизации проектов;
  • информация не используется для рекламы и не передаётся третьим лицам.

3.3. Назначение результатов

  • все расчёты носят справочно-информационный характер;
  • перед практическим применением требуется проверка у квалифицированного специалиста.

4. Права и обязанности

4.1. Пользователь вправе:

  • использовать приложение бесплатно или в рамках подписки PRO;
  • создавать и хранить собственные проекты;
  • обращаться к разработчику по техническим вопросам.

4.2. Пользователю запрещено:

  • использовать результаты приложения как проектно-сметную документацию;
  • представлять расчёты VoltHome как официальные инженерные заключения;
  • изменять, распространять или копировать приложение без письменного согласия разработчика;
